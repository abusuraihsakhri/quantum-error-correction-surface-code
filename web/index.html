Quantum error correction · research simulator

Rotated surface code

Simulate independent depolarizing errors on a distance-d planar code. Measure ideal stabilizer syndromes and decode using shortest-path defect matching.

Simulation settings

Independent X, Y, or Z error, each with probability p/3.

Ideal syndrome measurements only; no measurement faults, repeated cycles, gate errors, or hardware noise. Matching is exact for up to 18 defects per syndrome type and approximate beyond that.
